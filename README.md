# getwechaat-api

Backend API and WhatsApp bot for GetWeChaat — digital ordering and inventory for home-based sellers.

## Setup

```
npm install
cp .env.example .env   # fill in your keys
npm run dev
```

## Stack

Node.js + Express, Supabase (Postgres), Puppeteer (PDF invoices), Razorpay/Cashfree (payments), AiSensy/Wati (WhatsApp Business API).
